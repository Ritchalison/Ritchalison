## Featured Projects

### V-TRAP — Vulnerability Triage and Remediation Advisory Planner

My undergraduate final-year project, developed with [Elorm Kwasi Blabu](https://github.com/B2580777777).

A post-scan decision-support system for **context-aware vulnerability prioritisation and remediation planning**.

The implemented workflow combines scanner ingestion and normalisation, asset matching, human review of uncertain records, contextual risk scoring, remediation-strategy selection, advisory playbooks and remediation tracking.

Built with **Python, Flask, SQLAlchemy and SQLite**, with **Pytest, Ruff, Mypy and security checks** supporting the development workflow.

The source repository is currently private.

### [BalanceDesk](https://github.com/Ritchalison/BalanceDesk)

A **local-first, offline application** for daily sales, customer credit, payments, expenses, reconciliation and Business Day closure.

I defined the product requirements and workflows and reviewed the implementation against them.

Its implemented workflows include local account management, Standard and Administrator workflows, business-day controls, transaction history, credit tracking, controlled corrections, reconciliation, audit history, backup, restore and local data-recovery tooling.

The application follows a **local-only privacy model** and does not require a hosted database, cloud authentication or remote backend.

## How I Work

I aim to keep my technical work **evidence-driven, reviewable and clearly scoped**.

That means distinguishing between:

- observed behaviour and assumptions;
- validated findings and unverified possibilities;
- automated output and human-reviewed conclusions;
- working implementation and planned functionality.

I also use **AI-assisted development** for architecture exploration, requirements analysis, implementation review, testing and documentation, but I still verify the work against the requirements, the implementation and the available evidence.
